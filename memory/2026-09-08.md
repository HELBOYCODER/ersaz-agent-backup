## OpenCode Free Provider Fixed & Filtered to Free Models (2026-09-08)
- **Problem**: 9Router did not include OpenCode in `providerConnections` because OpenCode Free uses `noAuth: true` (no API key required), which caused 9Router to exclude all `oc/` models from `/v1/models` and fail in the UI.
- **Fix Applied**:
  - Initialized `opencode` in SQLite database `providerConnections` (`id: opencode-free-conn`, `authType: noAuth`, `isActive: 1`).
  - OpenCode Free automatically filtered to 100% free models via 9Router's internal `opencode-free` suggested filter:
    - `oc/mimo-v2.5-free` (Verified ✅)
