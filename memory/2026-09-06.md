## Suni Techno — Volume Slider & Channel Navigation Complete Isolation (2026-09-06)
- **Root Cause**: Range slider (`<input type="range">`) interaction on Android/WebKit dispatches ArrowLeft/ArrowRight keyboard events and touch bubbling. The global `keydown` listener caught those and called `nextChannel()` / `prevChannel()`, causing channel switching whenever volume was touched or slid.
- **Fix Applied**:
  1. Isolated volume deck (`#volDeck`) and slider (`#volSlider`) with `event.stopPropagation()` on touch/click/key events.
  2. Guarded global `keydown` listener to explicitly ignore when focus is on `INPUT` or within `#volDeck`.
  3. Dropped ambiguous touch swipe gesture from `channelCard` to prevent accidental channel switches when manipulating volume.
  4. Added `navigator.mediaSession` metadata + track handlers (`previoustrack`/`nexttrack`) so Android media notification separates track skip from hardware volume.
- **Commit**: `d07eb69` pushed to `main` (Live on https://3krbkbkrbrbg.github.io/suni-techno/).

- **Repo**: `DeusData/codebase-memory-mcp` (v0.10.8)
- **Capability**: Extremely powerful on full Linux/macOS/Windows systems: 158 languages, AST parsing, creates comprehensive Knowledge Graph (call chains, data flow, blast radius, architecture) with 120x token reduction compared to file-by-file search.
- **Root Cause on Android PRoot**:
  1. Relies on a strict background daemon process that orchestrates workers via custom UNIX domain sockets with ancestry verification (`CBMPEN` / `CBMSOC`).
  2. Inside Android PRoot with `--link2symlink`, filesystem sockets fail on `bind()` / `rename()` with `EPERM` (Operation not permitted).
  3. No fallback to in-process execution is provided upstream (`Indexing worker could not be started. Supervision is mandatory in a CBM host, so no in-process fallback was attempted`).
- **Conclusion**: Excellent concept and must-have for developer desktop/server setups (VS Code, Cursor, Claude Code), but requires native kernel socket support or root namespace to run daemon on mobile sandbox.
