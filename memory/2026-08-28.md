### Providers configured
- **cline**: default "inclusionai/ling-3.0-flash-fin:free" — requires web login via `authkit.cline.bot/device`
- **openrouter**: "z-ai/glm-5.2:free" set — needs OPENROUTER_API_KEY

- `z-ai/glm-5.3-flash` — GLM 5.3 Flash / Ox Alpha
- `z-ai/glm-5.2:free` — free tier available

### Usage
```bash
# With Cline provider (needs login first)
cline auth cline
# Then use: cline "your prompt"

# With OpenRouter (needs API key)

# Then use: cline --provider openrouter "your prompt"
```

Non-interactive sandbox can't complete web OAuth/device-code flow. User must authenticate interactively in their own environment or provide API keys.
