- **Repo**: `git clone https://github.com/google/mantis.git`
- **Authors**: Nick Galloway & Yulong Zhang (Google Staff Security Engineers)
- **Architecture**: Multi-agent sequential pipeline + sandboxed reproduction
- **Token Reduction**: 85%+ via Hierarchical Security Summary Tree (directory-level condensation)
- **Key Pipeline Stages** (in order):
  1. `/mantis-history` — Analyze VCS history + past vulnerabilities
  2. `/mantis-structural-index` — Build content-addressed semantic-unit index
  3. `/mantis-summarize` — Generate `mantis-summary.md` directory maps
  4. `/mantis-architecture` — Synthesize KB (Knowledge Base) from codebase + learnings
  5. `/mantis-threat-model` — Iterative threat model generation
  6. `/mantis-plan` — Map external boundary + build scanning roadmap
  7. `/mantis-researcher` — Multi-threaded security flaw sweep
  8. `/mantis-dedupe` — Consolidate overlapping files/duplicate bugs
  9. `/mantis-review` — Verify code validity + filter false positives (Negative Filter Rule)
  10. `/mantis-critic` — Eliminate non-viable production issues
  11. `/mantis-reproduce` — Generate PoC crash reproducers in sandbox (gVisor + Docker)
  12. `/mantis-patch` — Generate patches (optional)
- **Sandboxing**: gVisor (`runsc --network=none`) + Docker containers for executing AI-generated crash code
- **Agents**: Critic, Review, Researcher, Reproducer, Patcher + Meta-Agent orchestrator
- **CLIs**: Gemini CLI, Antigravity CLI, Google ADK, Antigravity SDK
- **Key Advantage**: False positive filtering via critic agents + sandboxed ground-truth reproduction
- **Roadmap**: Continuous pipeline (snapshot-per-pass on living codebases), Self-improving SKILL.md (meta-learning), Software Dark Factory (autonomous red-teaming gate for CI)
